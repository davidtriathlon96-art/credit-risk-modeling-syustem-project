# credit-risk-modeling-syustem-project
# Machine Learning Credit Risk Engine

## 📌 Overview
This project builds a machine learning model to predict the probability of loan default based on customer financial data.

The goal is to simulate a real-world credit risk system used by banks and financial institutions.

---

## 🧠 Problem Statement
Banks need to evaluate whether a customer is likely to default on a loan.

This project uses data-driven methods to classify customers into risk levels.

---

## ⚙️ Features Used
- Age
- Income
- Loan Amount
- Credit Score
- Employment Years
- Debt-to-Income Ratio

---

## 🤖 Model
- Random Forest Classifier
- Train/Test Split (80/20)

---

## 📊 Evaluation Metrics
- Accuracy
- Precision / Recall / F1-score
- Confusion Matrix

---

## 📈 Output
- Default prediction (0 / 1)
- Probability of default
- Risk segmentation:
  - Low Risk
  - Medium Risk
  - High Risk

---

## 🧩 Key Insights
- Credit score and debt-to-income ratio are strong predictors of default
- Model achieves high accuracy on test data
